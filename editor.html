🔑 Accesso a GitHub

Il token serve solo per salvare sul repository: leggere e modificare le domande funziona anche senza.
Incolla il tuo token personale: resta solo in questo browser (localStorage) e viene inviato unicamente a api.github.com. Non finisce mai nel sito pubblicato.
Come creare il token (2 minuti) GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories → scegli questo repo → Permissions → Repository permissions → Contents: Read and write. Nient'altro serve. Metti una scadenza breve.
Il token viene salvato in questo browser solo dopo la verifica. Su un dispositivo condiviso usa “Dimentica token” quando hai finito.
